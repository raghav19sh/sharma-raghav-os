# Sharma-Raghav OS

A rebuilt, workstation-style cybersecurity portfolio for Raghav Sharma.

The public home page contains only the selected portfolio areas:
- About
- Research
- Projects
- Security Lab
- Settings
- Music

The desktop UI is local and interactive: windows can be opened, focused, dragged, minimized, maximized and closed. The terminal, file browser, music player and security tools run in the browser.

## Run

`npm install`
`npm run dev`

Production deployment is handled by Vercel from `main`.
